## 上架步驟（**這部分要使用者去做**）

1. 開 [Google Play Console](https://play.google.com/console) 建 Developer 帳號 **$25 一次性**
2. 「Create App」→ 填基本資訊（名稱、語言）
3. 上傳 AAB（從 Android Studio Build → Generate Signed Bundle）
4. 設定「App content」：
   - Privacy Policy URL: https://examking.tw/privacy
   - Ads: Yes + 選 AdMob
   - Content rating: 跑問卷
   - Target audience: 18+ 或 All
   - News app: No
   - Data safety: 跑表單（參考上面）
5. 上傳 Screenshots + Feature Graphic + App Icon
6. 寫 Store listing（用上面準備好的中英文 description）
7. Release → Production track → Submit for review
8. **審查 1-3 天，可能要求補件**
